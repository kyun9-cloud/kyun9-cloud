## About Me

- 데이터 기반 서비스, 대시보드, 차트 UI처럼 정보 구조가 중요한 화면을 만드는 데 관심이 많습니다.
- 기획 의도를 화면 흐름과 컴포넌트 구조로 옮기고, Figma부터 구현까지 일관된 UX를 유지하려고 합니다.
- LLM/AI 기능이 사용자에게 실제로 닿는 지점을 고민하며, 개인화·분석·추천 경험을 제품 안에 자연스럽게 녹입니다.
- SVG 차트, 인터랙션, 상태 관리, API 연동처럼 사용자가 자주 만나는 화면의 디테일을 단단하게 다듬습니다.
